👤 Part 1: For Hackathon Participants (10-Second Join)

Connect your laptop's AI coding assistant to the leaderboard in just 1 terminal command. No accounts, no plugins, and no Wi-Fi restrictions needed.

Supported AI Coding Assistants: Cursor IDE, Anthropic Claude Code, Google Antigravity, GitHub Copilot (CLI & VS Code), OpenCode, and OpenAI Codex.

🪟 Windows (PowerShell):

irm "https://hackathon-leaderboard-6m5i.onrender.com/join.ps1?name=YOUR_NAME&team=YOUR_TEAM" | iex

🍎 macOS / 🐧 Linux (Terminal):

curl -fsSL "https://hackathon-leaderboard-6m5i.onrender.com/join.sh?name=YOUR_NAME&team=YOUR_TEAM" | bash
🔒 Privacy & Security Built-In:
The local agentplay engine runs completely on your machine. It only sends numerical telemetry: tool names (bash, read_file), step durations, error counts, and git commit hashes. All code files, prompts, passwords, and API keys are automatically stripped before transmission.

Automatic Background Sync (Continuous Updates):

To have your score, tools, and commits stream continuously as you build during the event:

python sync_to_hub.py --hub https://hackathon-leaderboard-6m5i.onrender.com --name "YOUR_NAME" --team "YOUR_TEAM" --watch

🏆 Part 2: For Mentors, Judges & Organizers

1. 📺 Stage HUD for the Big Screen

Project https://hackathon-leaderboard-6m5i.onrender.com/stage onto the venue auditorium screen to show live podium standings (1st, 2nd, 3rd place) and a high-energy rolling activity ticker showing commits and tool runs live.

2. 🔍 "See His Session" Interactive Replay Modal

Click on any participant's name in the leaderboard table to open the full session inspector:

  • Tool Breakdown: See Bash, MCP servers, and WebSearch volume.
  • 175-Step Chronological Timeline: Inspect tool calls, execution durations, errors, and retries.
  • Run Health Score: 0–100 benchmark evaluating stability and error recovery.

3. 🚨 Mentor SOS Alert

If an AI agent gets stuck in a loop (≥3 consecutive errors or high failure count), a red ⚠️ Mentor SOS Alert lights up on the dashboard so mentors can immediately walk over and unblock the team.
